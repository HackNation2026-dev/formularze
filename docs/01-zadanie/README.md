# Zadanie — Cyfryzacja Formularzy

Cel: blankiet formularza -> analiza -> konfiguracja JSON elektronicznej e-usługi. Odbiorca: urzędnik cyfryzujący formularz.

Minimum: REST API dla wymaganych formatów, JSON zgodny z formatem COI i regułami projektowania, dokumentacja architektury.

Rozszerzenia: słowniki i dane inicjalne, nowy słownik, dynamiczne zależności, import przez GUI, wizualizacja e-usługi i walidacje.

Oryginały: [rejestr materiałów](../02-materialy/rejestr.md). [Punktacja](punktacja.md). Wersje materiałów lokalnych nie mają potwierdzonego numeru wydania organizatora; identyfikuje je manifest SHA-256.
